Installation

Connect your approved merchant account.

Gather the correct identifiers and credentials before configuring a plugin or custom integration.

Use test credentials in test environments. Never publish, commit, or email a private API key.

1. Confirm your Merchant ID

Sign in to your assigned merchant portal and locate the Merchant ID for the account you are connecting.

2. Obtain the public credential

Use the public credential issued for the correct environment.

3. Store the private credential securely

Enter it only in a protected server-side field. Never expose it in browser code or screenshots.

4. Configure and test

Select the correct market and environment, then test approved, declined, refund, and reporting scenarios.

5. Complete launch review

Confirm production credentials, event handling, operational contacts, and merchant configuration.
